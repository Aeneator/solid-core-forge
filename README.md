# SOLID CORE FORGE

## How to get the project running

- Install the dependencies

```
npm install
```

- Command to rebuild and redeploy the website

```
./dg.ps1
```

- How to add new images:
  - Open the `public/HomeGallery` folder
  - Make a new folder for the new project image set (the name of the folder will be the title on the website)
  - Add the images
